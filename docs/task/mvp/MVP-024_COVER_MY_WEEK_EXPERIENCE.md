## Outcome and user value

Add the defining intelligent action on top of manual planning: the user locks what matters, the controller fills or repairs the rest, the UI shows only material unresolved decisions, the user accepts or swaps, and the shopping list is already derived. Default states trend toward "This week is covered" or "N things need you"; no feed, streak, or engagement surface.
