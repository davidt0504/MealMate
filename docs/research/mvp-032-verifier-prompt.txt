A. FRESH-CONTEXT RIGHTS REVIEW  (required by the card's AC-2 evidence plan)
------------------------------------------------------------------------------------------

Scope: every recipe in starter_recipes.json whose `provenance.rights.basis` is
"us_federal_public_domain". Note the path — the fields are nested under `provenance`, and
there is no top-level `rights` key on a recipe. A filter on `.rights.basis` returns nothing
and would read as "no federal entries ship", which is false.

Fields you will need, all under `provenance`: `source_url`, `source_name`, `source_author`,
and `rights.attribution`.

Use read-only web page reads only. No scraping tools, no bulk download, no authenticated
requests — the card's "External actions" row limits you to this.

For each entry:
  A1. Fetch `provenance.source_url`. Confirm it resolves, sits on a US federal domain, and is
      the recipe this entry claims — check the ingredient set against the page.
  A2. Compare `provenance.rights.attribution` against the source line the page actually
      prints. Quote both. Flag any entry whose attribution misstates the page.
  A3. Confirm `provenance.source_name` names a federal agency.
  A4. Federal authorship. There are TWO standards in play and you must report against both,
      because the card was amended mid-card and the amendment is itself a thing to check.

      The ORIGINAL wording, as committed at HEAD before this card ran:
        "A candidate qualifies only when its source line names a federal agency (USDA
         CNPP/FNS, NIH/NHLBI, CDC or another federal body) and that page's URL and source
         line are captured verbatim in the candidates document. Anything with a partner or
         unnamed source is excluded, however good the recipe."

      The AMENDED wording now in the working copy, approved by the owner on 2026-09-05, which
      accepts a three-field trace instead: the recipe page URL on a federal domain, the source
      line verbatim, and — where the source line names a collection rather than an agency —
      the URL of the federal page showing that collection is that agency's publication.

      Report, per entry, whether it qualifies under the ORIGINAL wording and whether it
      qualifies under the AMENDED one. If the two answers differ across the roster, say so
      loudly and quantify it: the amendment is what made this corpus eligible, so how much
      work it is doing is a material fact about the card. Then, independently of both, apply
      the exclusion neither wording relaxes: a collection developed with a named non-federal
      partner — a state body, a tribal organisation, a university, a company — fails,
      however federal the domain hosting it. Find each collection's own publication page and
      read what it says about who produced the recipes.
  A5. Read the entry's `instructions` beside the source page's directions. They must be
      independently worded, not a paraphrase. Say which you found.
  A6. Check each line's `original_text` against the source page's ingredient lines. Check
      every line if you can; if you sample, say what you sampled and why.

If a page will not load, record NOT VERIFIED with the HTTP status. Do not substitute a cached,
mirrored or third-party copy.

Report per entry: PASS / FAIL / NOT VERIFIED, the URL, and the quoted source line.
